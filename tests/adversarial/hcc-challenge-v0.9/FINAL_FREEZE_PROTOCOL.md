# Final extension closeout criteria

1. Identify exact final merged source and binary hashes, record all test archive identities and first-run vs post-fix evidence. Obtain 969/969 native curated cases at O0/O2 or independently adjudicate each exception, explicitly documenting residual limitations. Distinguish C11 constraint diagnostics from project rejection policy and GNU compatibility. Do not claim universal C11 conformance.
2. Preserve results for nine mixed-TU cases with both reference compilers, five strict-mode probes and 24 cross-target object cells at both optimization levels. Track runtime and mixed-ABI outcomes on each actual platform separately, including unavailable configurations. Native Linux x86-64 target-contract cases are not proof of all target ABIs.
3. Complete stress and generated workload campaigns, preserve denominators, timeouts, failures and seed sources. Native AArch64 and platform fallback thread-runtime verification are high-priority goals; if unavailable, explicitly record residual portability and weak-memory assurance gap and obtain user acceptance. Do not infer memory model correctness from a finite number of schedules. Include manual IR audit and sanitizer evidence if valid; absence of dynamic instrumentation is a limitation not a pass.
4. Confirm no unexpected internal/CI regressions, record all known unsupported features and failures, and application/platform support actually demonstrated. Reconfirm the frozen suites on final main after merge.
5. Preserve research record: human interventions, separate agent roles, frozen independent test design, actual defect categories (diagnostic, valid-program rejection, wrong code, runtime, ABI), repair iterations, time/cost evidence if measured. Include reference test design corrections and meaningful negative results. Do not count multiple parameterized manifestations as independent bugs, nor conflate compiler code generation with third-party library behavior. Distinguish measured from reported claims.
6. Close extension phase when reviewed evidence supports the agreed scope. The maximum of three additional rounds is exhausted; any unresolved important defect needs repair and retest of the same release, not a new broad curated round. Future maintenance is separate. No claims of full standard certification, production readiness or absence of latent defects.

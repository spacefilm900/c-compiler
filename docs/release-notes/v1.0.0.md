# hcc 1.0.0

The first release of **hcc**, the Haviland C Compiler: a clean-room C11
compiler written in Rust that emits textual LLVM IR, with Clang/LLVM as the
back end.

## Highlights

- **All of C11** except the optional complex types: VLAs, `_Atomic` and
  `<stdatomic.h>`, `<threads.h>`, `_Generic`, `_Alignas`, `_Thread_local`,
  `_Static_assert`, Unicode literals, K&R definitions and `<tgmath.h>`.
- **GNU C** with `-std=gnu11`: the extensions that real programs and the
  Linux and macOS system headers use.
- **Six targets**: Linux x86-64 and arm64, macOS arm64 and x86-64, and
  Windows x64 (MSVC and MinGW-w64), each with its platform ABI.
- **Real programs**, built by hcc and checked against Clang builds in CI:
  DOOM (frame for frame), Lua 5.4.7, SQLite 3.54.1, QuickJS (its tests and
  test262), zlib, and One True AWK.
- **Tested hard**: the Writing a C Compiler suite, the GCC torture tests,
  Csmith and YARPGen random programs, 969 adversarial cases, fuzzing of the
  compiler itself, coverage and mutation testing, and a weekly run on real
  arm64 Linux, macOS and Windows machines.

## New in this release

- `hcc --version`, and a regrouped `hcc --help`.
- `hcc --link`: compile and link a program in one command, with
  `lib/threads.c` and `-pthread` added automatically when a program uses
  `<threads.h>` on a platform that needs them.
- Messages show the source line with a caret; command-line errors say what
  is wrong.
- GNU forward-declared enums are incomplete until defined, as in GCC and
  Clang (#68).
- A user guide, a changelog, and contributing and security policies.

| Linux x86-64 (static) | `hcc-1.0.0-linux-x86_64.tar.gz` |
| Linux arm64 (static) | `hcc-1.0.0-linux-arm64.tar.gz` |
| macOS, Apple Silicon | `hcc-1.0.0-macos-arm64.tar.gz` |
| Windows x64 | `hcc-1.0.0-windows-x86_64.zip` |

Each archive holds `bin/hcc`, the compiler's headers (`include/`), the
threads runtime (`lib/threads.c`), the user guide, the changelog and the
licence. Check downloads against `SHA256SUMS`. hcc needs Clang/LLVM 18 or
newer to turn its IR into programs; see `docs/USER_GUIDE.md`.

## Known limitations

No `_Complex`; no object files or debug information of its own (Clang
does that step); inline assembly only without operands. The user guide
lists the rest.

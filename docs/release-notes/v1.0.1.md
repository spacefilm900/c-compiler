# hcc 1.0.1

A bug-fix release of **hcc**, the Haviland C Compiler. Nothing changes in
the command line, the accepted language (apart from the diagnostic below),
or the ABI of the code hcc emits. For everything else, see the
[1.0.0 release notes](v1.0.0.md).

## Fixed

- **A missing diagnostic for `register` parameters in old-style
  definitions.** C11 6.5.3.2p1 forbids taking the address of an object
  declared `register`. hcc already reported it in a function body and in
  a prototype's parameter list. In an old-style (K&R) definition,
  however, a later declaration in the parameter declaration list could
  still take the address:

  ```c
  void f(r, a) register int r; int a[sizeof &r]; {}
  ```

  This is now an error, as it is for a prototype parameter
  (`void f(register int r, int a[sizeof &r]);`).
- **Download checks.** The user guide and SECURITY.md said that each
  archive has its own `.sha256` file. The release publishes only
  `SHA256SUMS`, so both documents now show how to check against it:
  `sha256sum -c SHA256SUMS --ignore-missing`.
- The changelog dates 1.0.0 to 2026-11-25, the day it was released.

## Known limitations

These are unchanged from 1.0.0:
- No `_Complex`.
- The 6.7.4p3 inline-definition constraints are not diagnosed.
- hcc has no object files or debug information of its own; Clang does
  that step.
- Inline assembly works only without operands.

The user guide lists the rest.
